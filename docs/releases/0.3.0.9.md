# Zhuangzi 0.3.0.9

发布日期：2026-11-09。

本版包含 0.3.0.8 的全部功能及当前全部未发布修改。

## 本次更新

- “齐物论 → 深绿”改为 XYZ 三维平滑推进，速度按 192 米 / 7 秒计算（约 27.43 米/秒）。保留现有点位、潜水限制、入水 10 秒等待、停止及到达后 7 秒等待，以及 0.5 米到达容差。普通坐标、鼠标和地图标记传送继续沿用原有规则。水下平滑推进及停止功能已通过用户实测。
- 在“无限冲刺”下方新增“自动冲刺”，默认关闭。检测冲刺状态 ID 50，剩余持续时间不足 3 秒或状态消失时自动请求冲刺；实际使用通用动作 4（冲刺技能 3）。兼容正常技能冷却和既有无限冲刺刷新间隔；骑乘、多人坐骑副座及上下坐骑过程中暂停，下坐骑后恢复检测。总开关与移动卡片可停用并恢复该选项。
- 修复关盾调用探针收集插件清单时因版本信息为空导致加载失败的问题。缺失版本记为未知，单个插件信息读取异常不影响其他条目，列表刷新中断时保留上一份完整清单。PvP 实战录制复用相同读取保护，保留原有来源判定和日志字段。
- 调整“无视摔落伤害”：普通跳跃保留完整的起跳、顶点及落地通知；仅对已记录、落差超过 5 米的落地介入防摔。普通跳跃的他人视角起落动作已通过用户验证。
- 保留现有 RSR 汉化、原地复活、缩地、魔光键影、匿名、挖宝、自动补图、交易、PvP、麻将及其他功能与设置。

## 待验证事项

高落差防摔时，其他玩家视角下的落地延迟是否完全消除仍待进一步确认。

## 分发

源码仅同步私有源码仓库。公开分发仅包含混淆安装包、插件清单与说明，安装包不含源码、调试符号或混淆映射。

本地开发版最终使用正式公开包中的同一份 DLL，并核对版本号和 SHA-256 一致。
