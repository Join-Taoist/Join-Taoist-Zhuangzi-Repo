# Zhuangzi 0.3.1.0

发布日期为 2026-11-26。适用于 Dalamud API 15。

## 本次更新

- 「齐物论」新增魔法罐预测。打开独立窗口可查看四个大区的南北岛预测，点击卡片可在游戏地图上标记刷新点。
- 自动魔法罐支持跨区进岛、核对岛屿 ID、前往刷新点、参与 FATE、首次及追加寻宝。寻宝过程中会根据圣灵药提示缩减候选点，并处理岛内水晶传送和卡路脱困。
- 修复寻宝脱困失败后误跳过同岛下一只魔法罐的问题。离岛后，该岛的新一轮预测可重新参与自动筛选。
- 改进自动交易的分批交付确认，以及挖宝自动补图、房间到达与轮次衔接的处理。
- 同步金碟小游戏的当前国服兼容调整及相关回归检查。

## 安装

在卫月的插件管理中更新 Zhuangzi。首次安装可添加 [正式插件清单](https://raw.githubusercontent.com/Join-Taoist/Join-Taoist-Zhuangzi-Repo/main/pluginmaster.json)。
