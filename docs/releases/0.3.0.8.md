# Zhuangzi 0.3.0.8

发布日期：2026-11-04。

本版包含 0.3.0.7 的全部功能，以及当前全部未发布修改。

## 本次更新

- 新增“原地复活”，位于“逍遥游 → 特殊”，默认关闭。默认限制组队及附近存在玩家时使用；附近玩家检测范围可设置。记录死亡位置并处理返回与位置恢复；跨区域时优先使用已解锁水晶返回原区域。保留游戏原生复活确认与他人复活选择，无法返回的副本区域会停止恢复。
- 缩地支持 PvE（2262）和 PvP（29513）。开启“无视突进距离”或“无视突进位移”任一模式时，两种缩地均保持正常位移；范围内到选点，超出原生距离时沿三点一线截到最大可用距离，超距请求保留 0.05 米余量。
- “无视突进位移”对上述两种缩地作例外处理；其他技能继续沿用原有抑制规则。开关仍互斥，关闭后恢复原有范围判断。
- 补充 RSR 7.5.7.15 汉化：新增 375 条原文匹配，覆盖召唤、赤魔新增职业设置、通用说明、提示和下拉选项；词库共 1489 条，补充 83 个稳定设置标识并修正含义已变化的旧译文。继续保留旧版原文匹配，RSR 文件无需改写。
- 保留现有魔光键影、匿名、挖宝、自动补图、交易、PVP、麻将及其他功能与设置。

## 分发

源码仅同步私有源码仓库。公开分发仅包含混淆安装包、插件清单与说明；安装包不含源码、调试符号和混淆映射。

本地开发版最终使用正式公开包中的同一份 DLL，以版本号和 SHA-256 核对一致性。
