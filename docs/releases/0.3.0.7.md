# Zhuangzi 0.3.0.7

本次更新：2026-10-29。按用户指定版本号重新发布，包含原0.3.0.7全部功能及当前未发布修改。

## 本次内容

- 魔光键影完整自动循环：报名、进入、读取游戏原题、直接应答、结算退出及再次报名；修正禁字恢复、卡题衔接与自身攻击回执等待。
- 固定延迟200～2000ms（步进50ms）；循环次数0～999，0为无限。有限次数仅在确认结算并返回大厅后扣减；完成设定次数后停止。
- 可选自动兑换魔光键影宝箱（52450），每个910金碟点，每批1～9个，需点数和背包容量足够整批；核对实际商品、数量、金额和双重到账。购买确认配合YesAlready。
- 报名及兑换优先原地发包；失败且范围外时，使用vnavmesh地面寻路靠近再交互，不自动TP。路线可取消，具有占用、阻挡、超时及实际到达校验。
- 移除魔光旧词库、录制、导出及临时探针；保留旧记录清理及隐藏防暂离。新增目标坐标命令`/zz-txyz`。
- 兼容新版RSR反射与文本缓存变化，更新职业设置、显示名称与下拉选项汉化。新增文本未匹配时尽量保留已有覆盖。
- 补齐魔光活动相关界面的匿名替换，并保留当前匿名、挖宝、交易、PVP、麻将及其他现有功能。
- 保留自动补图金额控件70,000～120,000金币、每次2,000金币的既有规则。

## 分发与验证

源码仅同步私有源码仓库。公开分发仓库仅保存混淆安装包、清单与说明，安装包不包含源码、PDB或混淆映射。正式发布后，本地开发版使用公开正式包中的同一份DLL，并核对版本、SHA-256与加载情况。

魔光模块启动仍需用户手动操作；重启或热加载不会自动开始循环。NPC的最远发包距离未硬编码为25米，按实际窗口响应判断。
